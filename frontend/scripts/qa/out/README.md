# out/ 目录说明：本目录现存文件全部是「改名前」的历史快照

## 结论

本目录下的一切 JSON **都不是当前（2026-09-25 16:33 改名之后）的探针输出**，
而是「研究工作流 → 深度研究」改名**之前**用旧文案跑出来的历史快照。

## 依据（三条，互相印证）

1. **时间线**
   - `src/` 的改名落地时间：**2026-09-25 16:33 ~ 16:34**（`App.tsx` / `ResearchWorkflow.tsx` / `ResearchPlanner.tsx` 等）。
   - 本目录最新的文件：**2026-09-25 13:35**（`probe-r2-768.json`）。
   - 改名比这批产物**晚约 3 小时**。产物不可能是改名后的输出。

2. **内容里的实测文案与旧名一一对应**
   - `probe-1440.json` 里捕获到的导航菜单是
     `["概览","研究工作流","研究规划","智能体","知识库","教程","研究报告","效果评估","系统设置"]`，
     且「研究工作流」页的主按钮捕获文本是 `"启动研究工作流"`。
     当前代码里该按钮文案已是 `启动深度研究`，页面标题已是 `深度研究`——产物与现状不符，
     正说明它是旧版 DOM 的抓帧。

3. **产物形态与 `viewport-probe.js` 的返回体逐字段吻合**
   - 顶层键 `navInit / pages / viewport`，与 `viewport-probe.js` 的
     `{ viewport, navInit, pages }` 一致；
   - 单页键 `activeTitle / bodyScrollW / clicked / innerW / overflowPx / page / primary / scrollW`
     与 `viewport-probe.js` 逐字段一致。
   - 即：这些文件由 `qa/viewport-probe.js`（经 agent-browser 注入页面上下文）产出，
     **不是 `qa-probe.mjs` 产出的** —— 后者按设计只往 stdout 写 JSON，从不落盘。

## 因此

- **禁止手工编辑这些文件。** 手工把「研究工作流」替换成「深度研究」等于伪造历史：
  它描述的是一个从未存在过的状态（旧代码 + 新文案），会误导后人。
- **禁止把它们当作本轮改名的验收证据。** 它们证明的是改名前 13:35 那次运行。
- **`scripts/qa/summarize.mjs` 现在会拒绝出结论。** 已加「陈旧数据闸门」（判据见 `qa/rename-marker.mjs`）：
  产物 mtime 早于改名落地时点，**或**内容里含改名前旧文案，即判 `STALE-DATA` 并**不输出任何
  通过/失败结论**（退出码 2）。
  实测输出：四个宽度全部 `STALE-DATA —— 拒绝出结论`，末尾明确写出
  「上面任何逐页数字（含「溢出+NNNpx」）描述的都是【改名前】的布局」。
  **这是刻意的设计：注记挡不住工具，所以让工具自己也拒绝。**
  以前它会输出 `===== 溢出/首屏失败计数: 2 =====` 并把「研究工作流」列为 `❌溢出+176px`，
  那个数字极易被误读成「改名引入了横向溢出」，从而导向一次针对不存在缺陷的修复。
  因此**改名后 375px 是否仍溢出，目前仍然是未知的**，必须重跑才能回答。

## 探针工具的已知债（登记，不假装已排期）

| 债 | 位置 | 危害 |
|---|---|---|
| 找不到目标标签时**静默中断 / 静默少测** | `qa/loading-probe.js` 的 `nav()`：`.find()` 未命中时 `b` 为 undefined，直接 `b.dispatchEvent(...)` 抛未捕获 `TypeError`，整个探针中断，无 try/catch、无逐页降级 | 会**伪装成「跑过了」**。本轮改名之所以没当场炸，只是因为 4 个页面名恰好都在 |
| 找不到目标标签时**静默跳过一页** | `qa/viewport-probe.js` 的 `clickNav()`：未命中返回 `false` 后循环继续，照常输出 JSON，只是少测一页（`out.pages[].clicked` 已是 `false`，但没有消费方检查它） | 比抛异常更难发现：JSON 看着完整，实则少一页 |

**触发条件：下次改动探针页面清单时一并修。** 本轮的实现角色已离线，不登记排期。

## 要生成「当前输出」该怎么做

1. 起 dev server；
2. 用 agent-browser 把 `qa/viewport-probe.js`（或 `qa/loading-probe.js` / `qa/theme-contrast.js`）
   注入页面上下文执行，取其返回体；
